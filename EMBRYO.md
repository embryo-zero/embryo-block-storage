# Embryo Block Storage

Embryo Block Storage is Embryo-Zero's fork of [longhorn](https://github.com/longhorn/longhorn) (v1.14.0-dev-20261116, commit 9ff9b44). It does replicated disks for Kubernetes.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
